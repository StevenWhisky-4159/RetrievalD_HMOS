# Indexing Experiments

本目录记录尚未应用到生产索引的实验方案。每次实验应记录：

1. 实验目的与待验证假设。
2. 与当前生产方案的差异。
3. 输入数据、参数和执行命令。
4. 量化结果与典型样例。
5. 风险、结论及是否应用到生产。

实验产物统一保存到 `../data/experiments/`，不得覆盖生产索引。

## 2026-08-19：文章级第一类词正文匹配

### 目的

验证正文匹配第一类完整词时，将匹配范围从“当前分片自己的第一类词”扩大到
“同一 Markdown 文章所有分片汇总出的第一类词”，是否能发现正文对同文章其他章节的引用。

### 对照方案

生产方案：

- 每个分片只使用自己的子目录中英文名、标题层级和上层目录。
- 正文只匹配长度至少为 2 的当前分片第一类词。

实验方案：

- 按 Markdown 路径聚合同一文章的全部分片。
- 合并文章内所有分片的第一类词。
- 每个分片正文使用文章级第一类词集合进行匹配。
- 最小匹配长度仍为 2。

### 执行

```powershell
.venv\Scripts\python.exe scripts/retrieval_engine/indexing/experiments/compare_article_exact_matching.py
```

脚本：

`compare_article_exact_matching.py`

结果：

`../data/experiments/article_exact_matching_report.json`

### 数据规模

- 文章数：20,701
- 分片数：264,947
- 平均每分片第一类词：9.8110
- 平均每文章第一类词：19.9774
- 单文章最大第一类词：728

### 结果

- 分片级正文命中：337,724
- 文章级正文命中：628,729
- 新增命中：291,005
- 相对增幅：86.1665%
- 命中增加的分片：66,282
- 命中增加的分片比例：25.0171%

典型样例：

```text
文章：基于RAG框架实现邮件智能问答
分片：概述

分片级命中：0
文章级命中：4

新增：
RAG会话 ×2
LLM部署与调用 ×1
知识库构建 ×1
```

### 结论

文章级匹配能够识别正文对同一文章其他章节的引用，召回的第一类完整词明显增加。
但它也带来以下风险：

- 正文第一类词命中总量增加约 86%，可能放大标题词权重。
- 25% 的分片词频发生变化，需要重新评估 BM25 排名质量。
- 少数大型文章包含数百个第一类词，存在额外匹配开销和噪声。

### 决策

暂不应用到生产索引。生产索引继续使用“当前分片第一类词”正文匹配范围。
后续可结合离线检索评测，对比 Recall@K、MRR 和误召回后再决定。
